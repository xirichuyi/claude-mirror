# claude-mirror v0.19.0

本次更新统一应用名称与图标，并改进聊天、文件和 SSH 连接体验。

- 新图标：珊瑚色小怪兽，加入卷角与 ω 表情；应用名称统一为 `claude-mirror.app`。
- 统一暖色主题，调整侧栏、设置与会话选项；同步按钮放到新建对话右侧，搜索默认收起。
- 修复密码认证选项缺少输入框的问题，输入的密码接入本次 SSH 认证。
- 回答中的行内文件路径支持点击打开远端预览，修复 `file://` 路径处理。
- `/usage` 结果以用量卡片显示，改进命令搜索与历史命令输出。
- 改进回到底部按钮、回复失败提示与思考状态展示。
- 支持将指定项目的远端聊天记录移入可恢复备份目录，不删除项目文件。
- 右上角提供更新入口，每次启动自动检查新版本。

## 下载与安装

下载 `claude-mirror-0.19.0-macOS-arm64.dmg`，将 `claude-mirror.app` 拖入 Applications。

当前安装包适用于 Apple Silicon，要求 macOS 14 或更新版本。包内仍使用原应用标识，已有主机和会话数据沿用。旧版本名称为 `Claude Mirror.app` 或 `RemoteCC.app`，请退出旧版后安装新版，避免重复启动。

此版本为 ad-hoc 签名，尚未经过 Apple 公证。首次打开若被系统阻止，请核对下载来源后按 macOS 的“隐私与安全性”提示操作。
