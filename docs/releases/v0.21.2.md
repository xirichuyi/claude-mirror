# claude-mirror v0.21.2

改善 macOS 工作台交互，增加远端账号、订阅用量与额度保护，并整理界面组件和异步状态。

## macOS

- 左下角账号菜单提供账号信息、五小时及本周已用额度、重置倒计时和本地重置时间；查询不依赖选中会话。
- 用量入口直接读取账户状态；历史 `/usage` 未保存结果时提供说明及查看当前用量入口。
- 侧栏可调整宽度并记住设置；顶部操作收进菜单，会话详情仅在手动打开时显示。
- 统一中性毛玻璃、灰色侧栏选中与黑色主按钮，改善搜索焦点、空结果、加载提示、连接表单和文件操作。
- 拆分工作区、侧栏、编辑器、权限卡片等组件；统一弹窗路由，隔离扩展页异步请求，修复切页结果串页和插件重载后旧缓存回显。
- 调整主窗口布局，避免此前系统分栏与详情面板组合引发的布局崩溃。

## 远端运行环境（两个客户端共用）

- 五小时或本周任一周期已用达到 95% 时拒绝请求，并停止正在执行的 worker；无法确认额度时暂停请求。
- 同一远端登录下共享保护状态，达到 90% 后限制并行消耗；运行中每 5 秒检查用量。
- 用量统计有延迟，此机制不能保证精确保留 5%，也无法约束其他机器或其他客户端的消耗。API Key 等没有完整订阅周期数据的账户会被保护机制阻止。
- 新逻辑随新启动的 worker 生效；已驻留的旧 worker 不会被热替换。

## Windows

与 macOS 使用统一版本号，发布安装程序与便携包；本轮未调整 Windows 原生界面。共享远端运行环境包含上述更新。

## 验证与安装

本地 Node 113 项测试通过；Swift 79 项中 8 项依赖环境的测试跳过，其余通过。macOS 主要浏览、账号、搜索和文件预览路径已实机检查。权限批准、文件回退等真实变更操作未作为本轮实机测试执行。

macOS 安装包要求 macOS 14+、Apple Silicon；仍为 ad-hoc 签名，尚未经过 Apple 公证。已支持应用内更新的版本可在“账号 → 设置 → 关于”检查更新。Windows 安装程序及便携 ZIP 在同一 Release 提供。
