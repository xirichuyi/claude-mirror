# 镜像 Claude v0.18.0

本版重做了 macOS 界面，使它更接近原生应用；同时修复了 macOS 服务器上文件搜索没有结果的问题。

## 下载与安装

下载 **Claude-Mirror-0.18.0-macOS-arm64.dmg**，打开后将 **Claude Mirror.app** 拖入 **Applications**，替换旧版。聊天记录和机器配置会保留。已安装 0.17.0 的用户启动应用后会收到更新提示。

- 安装包：Apple Silicon（M1 及后续系列），macOS 14 或更新。
- 构建为 ad-hoc 签名，未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

## 界面

- 侧边栏改用 macOS 原生的玻璃材质，不再覆盖一层不透明的灰色背景。顶部显示当前机器及其连接状态，不再重复显示应用名称；间距按系统规范收紧，行高跟随“侧边栏图标大小”设置。
- 字号统一为系统文字样式，圆角统一为固定的几档。
- 发送按钮、主要按钮和未读标记跟随系统强调色。
- 聊天正文和输入框收窄到便于阅读的宽度；工具调用记录和用户消息气泡更紧凑；输入框默认两行高，文件传输状态只在有内容时显示。

## 修复

- macOS 服务器没有安装 ripgrep 时，文件内容搜索总是返回空结果。原因是 BSD grep 把 `-Z` 解释为解压缩，而不是以 NUL 分隔文件名；现在改用 GNU 和 BSD grep 都支持的 `--null`。

## 开发

- 新增 GitHub Actions：CI 运行 Node 和 Swift 测试并打包 DMG；推送 `v*` 标签时自动构建 DMG 并发布到 Release。
- 演示版可以通过 SSH 渲染自己的窗口截图，不需要“屏幕录制”权限（`macos/scripts/build-demo.sh`、`snapshot.sh`）。

## 校验

下载同名 `.sha256` 文件后，在文件所在目录运行：

```sh
shasum -a 256 -c Claude-Mirror-0.18.0-macOS-arm64.dmg.sha256
```
