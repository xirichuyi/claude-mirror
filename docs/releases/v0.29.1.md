# Tether v0.29.1

本次更新：文件走 QUIC 加速，对话选项弹窗简化。

## 三端

- 文件预览、下载、上传优先走 UDP（QUIC），实测比 SSH 快约 2.5 倍；UDP 不通时自动退回 SSH。
- 文件传输单独走一条通道，传大文件时对话和历史不再卡住。
- 对话选项只保留权限，默认跟随服务器上 Claude 的设置。
- “一键安装”点了直接开始。

## macOS

- 修复预览和下载同一文件时报“无法写入本地文件”。
- 打开文件夹后，空闲时在后台预加载缩略图和小文件。

## 服务器

- root 登录时，默认网络配置自动切到 BBR；自动在 ufw / firewalld 放行 UDP 47000–47099。云服务器安全组需要自己放行这段端口。
