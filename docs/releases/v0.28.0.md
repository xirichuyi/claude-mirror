# Tether v0.28.0

项目改名为 Tether。本次更新：服务器网页面板和一次性连接码，三端内置终端，断线约 20 秒内发现并自动重连。

## 三端

- 粘贴连接码添加服务器：不用填地址、账号和密钥，也不用确认指纹。首次连接时换成本机生成的密钥，连接码随即作废。
- 内置终端：走已有的 SSH 连接，在当前项目目录打开登录 shell。
- 断线约 20 秒内发现并自动重连；5 秒没回应先提示“网络响应较慢”。
- 成员页报错改成简短中文。

## 服务器

- `install-claude-remote.sh --panel` 安装网页面板：随机端口、路径和密码，只走 HTTPS。面板里可以添加、删除成员，复制连接码。
- `--invite NAME` 在终端生成连接码；连接码 24 小时内有效，只能用一次。

## macOS

- 回车后输入框立即清空，不再重复发送。
- Markdown 预览直接用已读取的内容，切回标签马上显示。
- 去掉“较新消息”按钮：滚到底自动接上新消息，箭头一次回到最新。

## Windows

- 下载断点续传；执行账号的附件走已有连接。
- 系统通知：回复完成、中断、需要确认、断线、重连。

## Android

- 浏览服务器文件，预览文本和图片；Git 改动和单文件差异。
- 删除成员改为带“取消 / 删除”的确认框。

## 其他
