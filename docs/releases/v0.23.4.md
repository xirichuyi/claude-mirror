# Claude Mirror v0.23.4

本次更新修复 macOS 对话区的几处显示问题。

- 回复中的长代码块限制高度，在块内滚动，不再占满多屏；流式输出时保持显示最新几行。
- 表格、代码和工具输出超出列宽时，右侧渐隐提示可以横向滚动。
- 提示消息移到窗口顶部，不再压住输入区。
- 引用块左侧显示竖线。
- 「思考过程」一行与工具调用一行样式统一。
- 拖选文字越过限高代码块时，先滚动代码块，可以选到块内被遮住的行。
- 变更列表中未跟踪文件显示 `U`，不再显示 `??`。

验证：自动化测试通过；在演示数据上核对了浅色、深色截图和流式输出场景。未通过真实 SSH 会话、Retina 屏幕和 120 Hz 屏幕验证。
