# claude-mirror v0.21.0

macOS 现在支持应用内更新。

- 每次启动自动检查新版，右上角也可以随时检查。
- 在更新窗口中下载、安装并重新启动，不用再手动打开 DMG、拖动替换应用。
- 更新包和更新源使用 Ed25519 签名，安装前验证。
- 退出前保存输入框草稿和已上传附件；未保存的文件编辑会提示确认。远端正在执行的任务保持运行。

**首次升级**：v0.20.0 及更早版本仍需手动安装一次本版 DMG；从 v0.21.0 起，后续版本可在应用内更新。

此版本提供 macOS 14+、Apple Silicon 安装包。Windows 原生预览版仍在独立 Release 中，本次没有加入 Windows 自动更新。
