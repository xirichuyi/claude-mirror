# 镜像 Claude v0.16.0

通过 SSH 在本地桌面使用远端 Claude Code，按服务器和项目管理对话、文件与任务。

## 下载与安装

下载 **Claude-Mirror-0.16.0-macOS-arm64.dmg**，打开后将 **Claude Mirror.app** 拖入 **Applications**。

- 本次安装包：Apple Silicon（M1 及后续系列），macOS 14 或更新。
- 本机无需 Node.js、Swift 或 Xcode。
- 远端需要 SSH、Node.js ≥18.14、可用的 Claude Code 及认证。
- 项目也包含跨平台 Electron 源码；本次没有 Windows、Linux 或 Intel Mac 的已验证安装包。
- DMG 内附远端安装脚本；发布附件也单独提供这两个脚本，下载后放在同一个目录。

## 本版内容

- 镜像 Claude 新名称、黑白界面和几何 C 图标。
- 命名主机与 SSH config、密码、私钥认证。
- 项目分组、按需读取历史、流式聊天和任务恢复。
- 从输入框拖入附件；远端临时存储、内容去重和同名新版本隔离。
- 远端文件浏览、预览、上传、下载、编辑与确认删除。
- 统一输入框与发送、停止、思考状态样式。

## 远端准备

```sh
sh setup-remote.sh my-server
# 指定端口和私钥：
sh setup-remote.sh -p 2222 -i ~/.ssh/id_ed25519 user@example.com
```

脚本通过 SSH 检查远端；已有 Claude 只验证不覆盖，缺失时使用官方 stable 安装器。不会自动登录或复制凭据，不自动安装系统 Node.js。完成账户认证后，在客户端连接同一个主机。

## 校验

下载同名 `.sha256` 文件后，在文件所在目录运行：

```sh
shasum -a 256 -c Claude-Mirror-0.16.0-macOS-arm64.dmg.sha256
```

## 已知限制

此构建使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名与 Apple 公证。首次启动可能被系统阻止；核对来源后，请从「系统设置 → 隐私与安全性」允许本次打开。不要关闭全局 Gatekeeper。

Claude 命令列表、模型和权限能力来自远端；部分复杂终端交互仍需继续适配。历史中的临时附件可能随服务器临时目录清理失效。服务器重启或远端进程退出不能保证任务继续。
