# claude-mirror v0.20.0

本次发布 macOS Apple Silicon（arm64）版本，要求 macOS 14 或更新版本。

## 修复内容

- **连续选中复制**：支持跨段落、列表、代码及消息拖选复制，保留 Markdown 标题、表格分列与文件链接。
- **会话打开位置**：进入会话定位到最新消息，修复排版后位置偏移；加载更早记录时保持阅读位置。
- **远端内存占用**：新 Worker 连续空闲 15 分钟后释放 Claude 和 Worker 进程，保留历史和会话 ID，下次发送恢复。正在回复、等待授权或有后台任务时不会回收。

旧版本已经启动的远端 Worker 不会自动更新，需要正常关闭并重新建立后才能使用新的回收机制。本次没有强制清理旧进程。

## 安装

下载 `claude-mirror-0.20.0-macOS-arm64.dmg`，打开后将 `claude-mirror.app` 拖入 Applications 替换旧版。保留原有配置和会话数据。

本版本为 ad-hoc 签名，尚未经过 Apple 公证。核对来源后，可在系统设置的“隐私与安全性”中允许打开。

附带 SHA-256 校验文件与远端准备脚本。Windows 原生版仍是独立预览版，请使用对应的 Windows Preview Release。
