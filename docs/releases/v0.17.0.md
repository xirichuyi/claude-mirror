# 镜像 Claude v0.17.0

通过 SSH 在本地桌面使用远端 Claude Code。本版新增服务器反向连接本机、自动检查更新，以及跨机器同步记忆和会话。

## 下载与安装

下载 **Claude-Mirror-0.17.0-macOS-arm64.dmg**，打开后将 **Claude Mirror.app** 拖入 **Applications**，替换旧版即可。聊天记录和机器配置会保留。

- 本次安装包：Apple Silicon（M1 及后续系列），macOS 14 或更新。
- 本机无需 Node.js、Swift 或 Xcode；远端需要 SSH、Node.js ≥18.14、可用的 Claude Code 及认证。
- 构建为 ad-hoc 签名，未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。

## 本版内容

### 服务器反向连接本机

在机器菜单中右键服务器，勾选“允许此服务器反向连接本机”。服务器会通过应用已有的 SSH 连接登录这台 Mac，不用另开隧道，也不需要公网 IP 或端口映射。

- 默认关闭，每台服务器单独开启。
- 服务器端只使用一个私有 Unix socket，不监听 TCP 端口；断线重连后自动重新建立。
- 服务器获得一把专用密钥，限定只能经由该通道登录；取消勾选后会立即从 `authorized_keys` 删除，离线时也会删除。
- 自动在服务器上固定本机的主机公钥，并生成支持连接复用的 ssh_config；菜单中可复制连接命令。
- 反向连接建立期间，Mac 不会因闲置自动休眠。
- 需要本机开启“远程登录”，服务器安装 `socat`。

### 检查更新

应用启动后会查询 GitHub Releases，之后每天最多查一次；发现新版本时可下载 DMG、查看更新内容或跳过此版本。菜单中新增“检查更新…”。应用不会自动替换自身。

### 跨机器同步记忆和会话（`scripts/agent-sync.cjs`）

- 在 VPS 和本地之间双向同步 Claude 的项目记忆，冲突时两个版本都保留。
- Claude Code 与 Codex 的会话生成脱敏交接记录，另一台机器可以读取后接手，也可以下载原始会话后用 `resume` 恢复。
- 由 Claude Code hook、Codex `notify` 和定时任务触发，只通过 SSH 传输，从不读取凭据。

## 校验

下载同名 `.sha256` 文件后，在文件所在目录运行：

```sh
shasum -a 256 -c Claude-Mirror-0.17.0-macOS-arm64.dmg.sha256
```
