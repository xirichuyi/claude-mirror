# Tether v0.29.0

本次更新：Git 改动逐行评论发给 Claude，Android 分享和图片缩略图，Windows 自动更新改进，Android 正式签名。

## 三端

- Git 差异里可以逐行评论，评论合成一条消息发给 Claude。
- Claude 拒绝回复时，可一键换备用模型重试；被撤回的半截回复从对话里删掉。

## Android

- 对话里的图片显示缩略图。
- 从相册或其他 App 分享文件和文字进来，选一个对话后放进输入框，不会自动发送。
- 版本号和产品一致，APK 改为正式签名。**已装旧版的需要先卸载一次再安装**，之后可以直接覆盖升级。

## Windows

- 每 4 小时检查一次更新，下载中断后接着下，退出时自动安装。
- 本版需要手动安装一次，之后自动更新。

## 其他

- CI 升级到 Node 24 版本的 actions。
