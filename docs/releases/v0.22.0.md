# Claude Mirror v0.22.0

本次界面与交互更新适用于 macOS；Windows 延续原生客户端界面，并随附本版远端代理。

- 按 Winc 调整侧栏、图标、按钮、文件标签与菜单，右上角只保留同步、分支和导出。
- 底栏显示账户、五小时及本周订阅用量；网络刷新失败时保留账户信息，明确标记用量不可用。
- 聊天记录后台读取，快速切换合并同步请求；已打开文件直接切换，并保留最近三个预览视图。
- 集成 Winc 原始预览解析与解码代码，支持图片、SVG、Markdown、CSV/TSV、XLSX/XLSM；PDF 沿用 PDFKit。
- 修复聊天中的文件夹链接，恢复文件下载的直接入口，调整聊天布局与滚动跟随。

验证：服务端 114 项测试通过；客户端测试发现的根目录旧断言已修正并复测。真实 SSH 上传下载、文件夹跳转、历史同步、重连、账户和两个额度周期复测通过；5 类 Winc 文件桥接测试通过。远端验证曾发生一次 SSH 断开，重试通过。

已知限制：本轮最终 macOS 点击、滚动与连续切换的实机验收因锁屏未完成；Winc 预览的解析和解码已集成，尚不具备其全部显示交互（如表格合并单元格、公式和 Mermaid 渲染）。

macOS 安装包适用于 Apple Silicon、macOS 14+，使用 ad-hoc 签名，尚未经过 Apple 公证。Windows 为原生预览版。
