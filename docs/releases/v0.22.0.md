# claude-mirror v0.22.0

macOS 客户端的流畅度与显示修复。

- 流式回复更省资源：每个片段只刷新正在生成的那条回复，侧栏、输入区和其它消息不再跟着重算；已完成的 Markdown 段落不再重复构建。
- 流式输出时对话会跟随到最新内容；向上阅读时停止跟随并显示“回到最新”，回到底部后恢复跟随。
- 打开或关闭侧栏、文件面板、会话详情，以及缩放窗口时，正在阅读的那一行保持不动；面板开合和切换对话有短过渡（开启“减弱动态效果”时关闭）。
- 对话里的代码块有语法着色并限高滚动；代码、工具输出和宽表格在右侧超出时以渐隐提示可横向滚动。
- 修复 Markdown 表格缺少右边框、引用块没有竖线、行内代码没有底色。
- 提示条移到窗口顶部，不再盖住输入区工具栏；短 diff 从编辑区顶部开始显示。
- 深色模式：主按钮和分段选择器的选中项清晰可见，侧栏、文件面板、会话详情与对话区的底色更接近。
- 机器切换弹层在按钮下方打开，不再伸出窗口；“思考过程”与工具行样式统一；变更列表里未跟踪文件显示为 `U`。
- 修复对话列变宽再变窄后，正文仍按旧宽度换行并被右侧截断的问题。

macOS 安装包适用于 Apple Silicon、macOS 14+，仍为 ad-hoc 签名，尚未经过 Apple 公证。Windows 为原生预览版，本次没有功能变化。
