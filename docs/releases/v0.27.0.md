# Claude Mirror v0.27.0

本次更新：Windows 界面对齐 macOS，界面文字精简，root 可直接开 Full Access，文件传输改走现有连接并支持续传，服务器没有 Node.js 也能连，支持多人共用一台服务器。

## macOS

- 删除“对话用量与上下文”弹窗，上下文用量只留在输入框旁。
- 图片预览先出缩略图，再自动补原图；目录预取缩略图。
- 队列的“继续”“清空”改为图标。
- 删除解释性小字，报错和确认只留一句。

## Windows

- 输入框：`Enter` 发送，`Shift+Enter` 换行，`Ctrl+Enter` 插队，`Esc` 停止；显示上下文 `已用 / 总量`。
- 队列：立即发送、编辑、移除、继续、清空。
- 侧栏：对话 / 文件 / Git / 搜索 放在服务器旁；目录与对话图标对齐。
- 状态页去掉账号用量和对话用量。

## 三端

- root 登录可直接开 Full Access：Claude 以 root 运行并带 `IS_SANDBOX=1`，不再要求执行账号。
- 文件传输走 agent 现有连接（二进制帧、按窗口限流），大文件传输时停止和确认不再卡住；下载和附件上传断线后续传。
- 服务器没有 Node.js 或版本过旧时，首次连接自动装到用户目录（校验 SHA-256），支持 Alpine 和较旧的 glibc。
- 多人共用服务器：root 登录时出现“成员”入口，可添加 / 删除成员。每人独立 Linux 账号、SSH 密钥和 Claude 登录，主目录互相不可见。

## Android

- 按 Claude 手机 App 重做样式。
- 多项目、目录选择、接着服务器上已有的对话、重命名、私钥文件导入。
- 切换模型和思考强度；后台跟随回复，完成或需要确认时通知。
- 照片和文件附件。

验证：自动化测试通过；Android 主要流程在模拟器上测过；成员管理在 Linux 容器中实测。Windows 只通过编译、启动检查和截图；成员页面未在任何客户端上实际操作过；未用真实 Anthropic API 测试。
