# Claude Mirror v0.23.3

本次更新优化 macOS 的远端工作目录选择。

- 项目选择器直接加载当前服务器的目录，支持逐层浏览、返回上级、返回主目录和输入路径后回车跳转。
- 移除打开项目、新建项目两个模式，只保留目录选择与内联新建文件夹。
- 精简工具按钮，沿用统一按钮与表单组件。
- 返回已浏览目录时先显示缓存，再校验远端结果；避免加载前清空列表、反复强制请求及界面刷新时重复排序。
- 取消或快速切换目录后，过期响应不再覆盖当前选择。

验证：本地 Release 构建、签名及格式检查通过；已通过真实 SSH 验证目录浏览、返回、路径错误提示与目录选择。未将这些检查视为全应用性能压力测试。
