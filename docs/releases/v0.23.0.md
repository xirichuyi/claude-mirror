# Claude Mirror v0.23.0

合并 macOS 聊天性能修复与 macOS / Windows 首次连接引导。

- 流式文本更新仅通知聊天区域；状态、审批和任务结束仍及时刷新界面。
- 历史采用每页最多 30 条的重叠分页，可查看更早、较新消息并回到最新，避免持续加载造成视图堆积。
- 长回复按完整段落分块，保留未变化正文的排版；修复按钮悬停、快速滚到底部时的重复刷新与跟随冲突。
- 重启后恢复远端任务订阅，分别显示 SSH 连接、任务恢复和后台运行状态。
- 首次连接增加 Node.js、Claude 安装与登录状态检查，提供安装、终端登录和免密配置入口；Windows 同步完善设置流程。
- 保留 Winc 文件预览、下载、账户与订阅用量入口。

性能验证：Release 构建使用独立测试数据，在原生 SwiftUI/AppKit 视图中连续两分钟执行 1,313 次模拟输出更新，全局界面刷新为 0；3,000 条历史翻阅 150 页，原生文本视图最多 30 个。该测试不等同于真实模型或公网网络性能保证。

macOS 安装包适用于 Apple Silicon、macOS 14+，使用 ad-hoc 签名，尚未经过 Apple 公证。Windows 为原生预览版。
