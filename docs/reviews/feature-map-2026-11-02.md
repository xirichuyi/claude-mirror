# 功能与入口梳理

按用户任务归为 8 类。远端 slash 命令、模型、Agent、技能、MCP 和插件列表随服务器变化，不计入固定总数；本表不代表完全覆盖 Claude Code 所有交互。

| 类别 | 已有能力 | 入口 |
| --- | --- | --- |
| 主机 | SSH 别名、地址/端口、密码/密钥、多主机切换、命名、重连/断开、反向访问 | 主机切换；设置 → 主机 |
| 项目 | 目录分组、折叠、项目内新对话、切换目录、浏览、隔离工作区、项目归档 | 项目及悬停菜单；对话顶部项目名 |
| 对话 | 远端历史同步、按需加载、搜索、固定、重命名、归档/恢复、删除、分支、导出 | 侧栏右键；固定归档；顶部对话菜单 |
| 消息与附件 | 流式回复、停止、排队、草稿、复制、拖入/选择文件、上传后远端引用、附件打开/下载 | 输入框和消息操作 |
| Claude 配置 | 远端模型、自定义模型、权限、思考强度、快速模式、输出样式、Agent、额外目录 | 输入框模型/权限；顶部模型与权限 |
| 命令与任务 | 命令发现、补全、交互、权限确认、任务动态、技能/Agent/MCP/插件信息 | 输入框命令；通知铃；会话工具 → Claude |
| 文件 | 目录树、隐藏文件、上传/下载、新建/重命名/删除、搜索、快速打开、文本/图片/PDF/Markdown 预览、编辑保存、本机打开、Git 变更、文件回退 | 文件面板、文件右键、预览工具栏、消息回退 |
| 状态与维护 | 历史刷新、任务状态、上下文/用量、SSH 端口转发、更新检查 | 同步状态；对话菜单；会话工具 → 端口转发；设置 → 关于 |

## 本轮调整

- 设置与归档固定在侧栏底部；设置支持 Command+,，不依赖打开对话。
- 主机设置提供连接/断开、重命名和反向访问开关。
- 分支和导出放在对话菜单；隔离工作区放在项目菜单。
- 会话工具分为 Claude / 端口转发；远端信息使用选择器，替代多排按钮。
- 首页最近对话移除白色容器和分割线，保留整行悬停反馈。

## 主题

主背景 #FAF6F2，侧栏 #F0EAE3，卡片/输入框 #F6F1EB，用户消息 #EDE5DC。附件、代码块、错误详情、选择器和应用内面板复用主题。编辑器取消系统白底。系统文件对话框、原生菜单与键盘焦点环保留系统行为；错误、警告、Git 增删保留语义色。

## 验证

Release 构建、签名校验和 diff 空白检查通过；实机检查首页、固定设置、主机设置与模型权限布局。未调用模型生成内容或更改权限，未测试破坏性文件操作。暗色保留独立主题值，本轮未逐页实机检查暗色。
