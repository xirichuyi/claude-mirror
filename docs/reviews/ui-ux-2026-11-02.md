# UI / UX review · 2026-11-02

本轮针对原生客户端的功能入口、文案和聊天布局。采用中性紧凑的工作区风格，沿用系统字体、语义色和现有主题令牌。

## 入口调整

| 功能 | 入口 |
| --- | --- |
| 上传聊天附件 | 输入框「附件」，保留拖放 |
| 远端命令 | 输入框「命令」，列表来自远端目录，选择后填入草稿 |
| 切换项目 | 输入框「项目」 |
| 模型与权限 | 顶栏「设置」，输入框保留快捷入口 |
| 文件管理 | 顶栏「文件」，文件面板「上传」 |
| 反向访问 | 左上主机菜单，保留权限说明与确认 |

删除首页宣传式介绍，缩短连接及偏好设置文案。最近对话默认折叠，项目仍为主要导航。错误显示短摘要，原始详情按需展开；仅隐藏与错误详情完全等价的重复正文。

## Apple 八项原则

| 原则 | 本轮结论 |
| --- | --- |
| Purpose | 改善：主界面聚焦对话、项目、文件 |
| Agency | 改善：命令填入草稿，不自动执行；保留现有操作 |
| Responsibility | 保留：反向访问仍有权限说明和原有确认 |
| Familiarity | 改善：常用图标配短标签，使用原生菜单 |
| Flexibility | 部分验证：宽聊天区及文件面板展开后的窄聊天区；未完整检查 VoiceOver 和深色模式 |
| Simplicity | 改善：缩短说明，折叠次要信息 |
| Craft | 改善：窄输入框自动两行；错误摘要和诊断分层 |
| Delight | 改善：减少重复信息、突兀的大红错误块和装饰性内容 |

## 验证范围

- ReplyFailureTests 和 FileDropTests：6 项通过。
- SwiftUI 演示构建：查看聊天、文件双面板及主机入口；演示环境不连接 SSH。
- 编译检查覆盖新增命令菜单；远端命令交互沿用原路径，本轮未对每个远端命令做端到端测试。
- 待后续覆盖：深色模式、完整键盘/VoiceOver 导航、超长自定义模型名和更小窗口。
