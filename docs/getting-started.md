# 入门指南

镜像 Claude（claude-mirror）让你在自己的电脑上使用**服务器里的** Claude Code：代码、依赖和 Claude 都在服务器上运行，桌面应用负责对话、审批操作和查看文件。关掉应用，服务器上的任务也会继续。

整个过程大约 10 分钟，分四步。

## 1. 准备一台服务器

需要一台**能用 SSH 登录**的 Linux 或 macOS 机器，例如：

- 云服务器（阿里云、腾讯云、AWS、DigitalOcean 等），购买时会给你一个 IP 地址、用户名（常见是 `root` 或 `ubuntu`）和密码；
- 公司或学校的开发机，向管理员要地址和账号；
- 家里另一台开着“远程登录”的 Mac（系统设置 → 通用 → 共享 → 远程登录）。

### 没有服务器？

- 最省事的是买一台入门级云服务器，选 Ubuntu 22.04 或更新版本，1 核 2 GB 内存就够用。
- 服务器需要能访问外网，Claude Code 要连接 Anthropic 的服务。
- 不需要提前安装任何东西，应用会帮你装好。

> 先确认能登录：在“终端”里运行 `ssh 用户名@服务器地址`，能输入密码进入就说明可以用了。

## 2. 安装并打开应用

### macOS

1. 从[发布页](https://github.com/xirichuyi/claude-mirror/releases/latest)下载 `claude-mirror-<版本号>-macOS-arm64.dmg`。
2. 打开 DMG，把 **claude-mirror.app** 拖进 **Applications**。
3. 从“应用程序”打开 claude-mirror。

**第一次打开被拦截怎么办？** 当前版本还没有经过 Apple 公证，macOS 会提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”。这不代表文件损坏。确认是从上面的发布页下载的之后：

1. 在提示框里点 **完成**（不要点“移到废纸篓”）。
2. 打开 **系统设置 → 隐私与安全性**，滚动到底部的“安全性”。
3. 找到“已阻止 claude-mirror”，点 **仍要打开**，输入登录密码。
4. 再次打开 claude-mirror，在弹窗里点 **打开**。

只需要做一次，以后的应用内更新不会再出现这个提示。请不要关闭全局 Gatekeeper。

### Windows

从[发布页](https://github.com/xirichuyi/claude-mirror/releases/latest)下载 `Claude-Mirror-Setup-x64.exe` 并安装，详见 [Windows 说明](../windows/README.md)。

## 3. 添加服务器

首次打开时选择 **添加服务器**；已有连接时，点左上角主机名 → **添加服务器…**：

- **服务器地址**：IP 或域名。可以把用户名一起写上，例如 `ubuntu@1.2.3.4`。
- **登录方式**：大多数云服务器选 **密码**。如果你已经在终端里用密钥登录过，选 **本机 SSH 配置**。
- 端口不是 22、或者想起个好记的名字，展开 **高级选项** 填写。

第一次连接时会弹出服务器指纹，确认地址无误后接受即可。

用密码连接成功后，应用会询问是否 **设置免密登录**。推荐设置：应用会生成一把专用密钥并加到服务器上，以后打开应用会自动连接，不用再输密码。

连接失败时，首页会说明原因（比如密码不对、地址写错、端口不通），并提供“重试”和“修改连接设置”。

## 4. 检查服务器环境

连接后应用会自动检查服务器，有问题时首页会显示提醒，处理好之前不会消失：

| 提醒 | 怎么处理 |
| --- | --- |
| 服务器缺少 Node.js / Node.js 太旧 | 点 **一键安装**。官方 Node.js 会装到你的用户目录，不需要管理员权限，也不影响系统已有版本。 |
| 服务器还没有安装 Claude Code | 点 **一键安装**，使用 Anthropic 官方安装程序。 |
| Claude Code 还没有登录 | 点 **在终端登录**，按提示在浏览器里授权，完成后点 **重新检查**。登录信息只保存在服务器上。 |
| 断开连接后回复会中断 | 服务器在 SSH 断开时会结束后台程序。复制提示里的命令在服务器上运行；没有权限时请管理员运行 `sudo loginctl enable-linger 你的用户名`。 |

全部通过后，点 **在主目录开始对话**，或 **打开或新建项目** 选择一个项目文件夹，就可以开始了。不知道问什么？对话页有“了解项目”“检查代码”等示例。

## 常见问题

**连接时提示“服务器拒绝了登录”**：用户名或密码不对。云服务器的用户名常见是 `root` 或 `ubuntu`，可以写在地址里：`ubuntu@1.2.3.4`。

**提示“连接超时”**：检查服务器是否开机，以及云服务器的安全组 / 防火墙是否放行了 22 端口。

**一键安装失败**：多数是服务器无法访问外网。可以在服务器上运行 `curl -I https://claude.ai` 测试。Alpine 等 musl 系统需要用系统包管理器安装 Node.js（`apk add nodejs`）。

**关掉应用后任务还在吗？** 在。重新打开应用会接上之前的输出和待确认的请求。

**反向连接是什么？** 让服务器反过来登录这台 Mac 的高级功能，默认关闭。它会让服务器上的程序能以你的身份操作这台 Mac，只在完全信任服务器时到“服务器设置”里开启。

## 管理已有连接

点左上角主机名切换服务器，或选择 **管理主机…** 编辑、删除连接。删除后聊天记录和远端文件会保留；需要再次连接时，重新添加服务器即可。

重新打开应用会恢复上次查看的聊天及其主机。底栏的 `5h` 和 `7d` 分别表示五小时、七天用量窗口，悬停可查看完整说明；账户默认显示缩写头像。
