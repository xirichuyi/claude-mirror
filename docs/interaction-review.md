# 2026-11-04 macOS 交互复核

参照：Claude Code 官方 Desktop 文档的 prompt box、session details、workspace panes 章节：https://code.claude.com/docs/en/desktop 。本机未安装官方 Claude.app；本次参照官方交互说明，并实际操作本项目客户端验证，不宣称做过官方 App 的实机操作。

## 发现和调整

此前账号、环境、运行控制分别藏在账号弹窗、右上角省略菜单和会话工具的两级选择器里。用户无法凭功能名称判断入口。

- 输入框旁的「添加」菜单包含文件、技能、连接器、插件和记忆入口，符合它们服务于当前输入的使用场景。
- 模型与权限保留在输入框下方；常用操作不移进设置中心。
- 标题栏提供带文字的「扩展」「会话详情」；省略菜单保留导出、分支等次要操作。
- 右侧会话详情直接显示环境、上下文、后台任务和项目配置快捷入口，支持收起；不会把未建立实时 owner 的历史会话显示成拥有实时上下文。
- 扩展窗口以可见左侧分类导航代替两级下拉，入口可以直接定位目标分类。
- 左下角只保留一行账号入口；点击打开紧凑账号菜单，顶部显示账号与订阅，下方为用量、账号详情、设置和断开服务器；不设帮助入口。“用量”进入同一浮层的详情页，显示五小时及每周已用额度与重置倒计时，并可返回账号菜单，避免常驻信息挤占会话列表。

## Apple 设计原则复核

| 原则 | 旧界面判定 | 本次调整与边界 |
| --- | --- | --- |
| Purpose | 违反：功能存在但不易发现 | 常用入口直接命名，围绕聊天使用路径组织 |
| Agency | 部分符合 | 保留草稿、命令填入后用户发送、侧栏可收起；没有自动更改远端配置 |
| Responsibility | 符合数据来源原则 | 未报告字段与不可用操作明确说明；不伪造即时状态 |
| Familiarity | 违反：多层工具下拉 | 输入框添加菜单、右侧 inspector、左侧分类符合桌面惯例 |
| Flexibility | 部分符合 | 原输入框窄宽自适应保留，使用系统 inspector；所有入口有文字或可访问名称 |
| Simplicity | 违反：相同功能入口含糊 | 账号、会话详情、扩展三种职责清楚；不靠原始 JSON 作为唯一入口 |
| Craft | 违反：只验收接口 | 实机点击分类、打开侧栏、截图检查布局；窗口标题清理历史命令标记 |
| Delight | 不适用装饰效果 | 此次重点为降低查找成本，无新增装饰或动画 |

### 崩溃报告核查与侧栏调宽

2026-11-04 核查本机 6 份 RemoteCC 崩溃报告。22:55:18、22:56:44、22:57:18 的异常栈包含 NSWindow._postWindowNeedsUpdateConstraints、NSHostingView.SizeConstraints.update 和 SplitViewChildController.hostingView，确认系统嵌套分栏存在布局约束反馈。另 3 份为布局阶段 SIGTRAP / SIGSEGV，符号不完整，不将它们断言为同一根因。最后一份报告为 22:59:13。

现有实现已取消会话区域的系统嵌套分栏，避免切换时反复协商最小尺寸。侧栏拖动独立于系统分栏：10 点命中区域、左右调整光标、全局坐标计算位移，范围 200–360 点，AppStorage 记忆宽度并支持辅助功能调整。

实机验证：拖动 240 → 320 → 260；打开会话、文件及详情同时展开、切换会话；重启仍保留 260。复查崩溃报告数量仍为 6，无新增。debug 构建、签名及 diff 检查通过。这是本轮场景验证，不代表已排除所有崩溃来源。


## 组件与状态重构验证（2026-11-04）

- `RootView` 仅负责根布局与呈现；工作区、侧栏、项目分组、机器切换、连接表单拆为独立文件。
- 输入区的 AppKit 编辑器桥接、候选菜单和权限卡片分别拆分，保持原有输入与附件行为。
- `AccountStore` 由 AppModel 持有，根视图按机器/连接状态启动观察；侧栏、账户详情共享数据和进行中的请求。收起侧栏不会销毁账户缓存。
- `SessionToolsStore` 用请求代次隔离异步结果；扩展页面采用类型化 section，按会话和页面身份分别持有状态。
- `AppPresentation` 统一应用弹窗、账户详情和命令选择器；旧弹窗的关闭动作不清除新的目标。
- 实机验证账号菜单、账户详情、收起/展开侧栏、宽度 260→280→260、技能/连接器/插件/状态切换以及状态页跳转模型与权限均正常。本次未复现崩溃。
- 异步回归测试覆盖离开页面后的迟到结果、旧请求结束不得清除新请求 loading、切换机器及请求去重。
- 远端插件重载同步 worker 与客户端快照；held 重载保留已有插件。
- 额度协调范围为同一远端登录：90% 限制并行，95% 共享停止线；5 秒读取用量，1 秒检查共享停止状态。SDK 统计延迟与其他客户端消耗仍无法通过此机制预留精确额度。
- 尚未把 AppModel 的连接、上传、通知等全部重写；本轮优先隔离已经导致错误的状态职责。

### 八项设计原则复核

- Purpose：符合。账户查看直接到数据，不再通过聊天发送命令绕路。
- Agency：改进。可退出搜索、取消表单、返回会话；涉及实际改写的操作未做本轮实机验证。
- Responsibility：符合本轮范围。显示真实用量与重置时间，保留额度反馈延迟说明，没有补造历史结果。
- Familiarity：改进。搜索焦点、Escape、中文动作与默认项一致。
- Flexibility：部分验证。实测当前最小宽度附近的聊天/文件并排与输入区换行，保留键盘操作；未实测 VoiceOver 完整朗读和深色模式。
- Simplicity：改进。机器菜单聚焦切换，用量保护规则折叠，任务中心去重复空卡片。
- Craft：改进。统一加载/空结果组件、关闭区域、辅助说明；搜索加载优先级在点击走查中发现并修正。
- Delight：符合。采用克制的原生材质与明确反馈，不新增装饰动画或颜色。
